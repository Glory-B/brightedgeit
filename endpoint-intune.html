Frequently asked questions

Got questions?

Here are some common questions about Endpoint & Intune.

Can you help with an existing Intune environment?

We can review an existing Intune environment and help identify configuration, policy and management improvements based on the agreed scope.

Can you help with new-device rollout?

We can help plan and configure supported Intune device-enrolment and rollout scenarios, including Windows Autopilot where appropriate.

Can Intune work with Microsoft 365 and Entra ID?

Yes. Intune commonly works alongside Microsoft 365 and Microsoft Entra ID for device, identity and access management.
